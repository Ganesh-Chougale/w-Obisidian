- `Example`  
here is a hypothetical example:
[An input box for product name] [SHOW Data Button]
radio box   - [] Closed Deal    []Ongoing Deal
- behavior
1. user type some letter of prodcut name, the input box will suggest the auto-completing names dropdown
2. user pick a product name => product id will be mapped to that input element
3. user click of SHOW button => sends product ID to backend fetch data from DB & gives us JSONResult
4. it will show table of data below
5. toggling between radio boxes (closed deal or ongoing deal) should automatically trigger show button

now the discussion is
- in normal case. we should bind json-result logic to show button click directly
- but within this case we should approach like this.

A. Create a universal data loading function.
```javascript
    function loadprodcutwiseData() {
        var productCode = $("#productInputBoxCode").val();

        // .... fetch logic
        // .... if success then populate table
        // .... if fails then show the fail message

    }
```  
B. re-use this function in all 3 events
b1. Show button
```javascript
    $("#showData").click(function (e) {
        e.preventDefault();
        loadprodcutwiseData();
    });
```  
b2. Re-trigger it on radio button
```javascript
    $("input[name='DealType']").change(function () {
        var productCode = $("#productInputBoxCode").val();
        if (productCode == "" || productCode == null) {
            return;
        }
        loadprodcutwiseData();
    });
```
