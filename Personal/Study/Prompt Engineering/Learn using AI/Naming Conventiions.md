## Naming convention
```
Goal
└── Phase
    └── Milestone
        └── Step
```
Example:  
```
Simple Full Stack App using JS
└── FRONT END
    └── Create Files
        └── index.html
        └── main.js
        └── sub_queries (folder)
    └── Implemete Index.html
        └── register & login Area which are hidden bydeafult
        └── 2 buttons which triggers the area on/off
        └── register button & login button
    └── etc.....
```
