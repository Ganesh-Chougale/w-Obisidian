## 17.3 Procedure

`Hypothesis Testing Procedure`: A systematic process used to test whether sample data provides enough evidence against the `Null Hypothesis (H₀)`.  

### Steps
1. `State H₀ and H₁`  
   * `H₀` → no effect/difference.  
   * `H₁` → effect/difference exists.  

2. `Choose Significance Level (α)`
   * Commonly `0.05`.  

3. `Collect Sample Data`  
   * Gather the data needed for the test.  

4. `Calculate Test Statistic / p-value`  
   * Use the appropriate statistical test.  

5. `Make Decision`  
   * `p-value ≤ α` → Reject `H₀`  
   * `p-value > α` → Fail to reject `H₀`  

6. `State Conclusion`  
   * Explain what the statistical result means in the context of the research.  

`H₀/H₁` → `α` → `Data` → `Test` → `Decision` → `Conclusion`  

### Remember
**Hypothesis testing = Set the claim → test with data → make a statistical decision.**
