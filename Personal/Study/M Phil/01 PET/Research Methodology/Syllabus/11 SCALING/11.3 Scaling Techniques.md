## 11.3 Scaling Techniques
`Scaling technique` = a way of asking someone to express their opinion/attitude in numbers or ordered choices.  
Imagine you want to measure:  
> “How good are GEN-AI responses?”  
You can ask the same thing in different ways.  
### 1. Likert Scale = Agree / Disagree  
You give a statement and ask how much the person agrees.  
* “Contextual information improves GEN-AI responses.”  
* `Strongly Agree | Agree | Neutral | Disagree | Strongly Disagree`  
👉 Likert = How much do you agree?  
---

### 2. Semantic Differential = Between Two Opposites
Give two opposite words and ask where the person places their opinion.    
* GEN-AI response:  
`Poor ────●──── Excellent`  
or   
`Useless ───────── Useful`  
👉 Semantic Differential = Where between two opposites?
---

### 3. Thurstone Scale = Statements Already Have Values  
The researcher prepares several statements and assigns values to them beforehand.  
* Statement A → value `2`  
* Statement B → value `5`  
* Statement C → value `8`  
* Statement D → value `10`  
The participant indicates which statements they agree with.
👉 Thurstone = Researcher gives statements pre-assigned values.  
---

### 4. Guttman Scale = Step-by-Step / Cumulative  
Statements are arranged from weak → strong.  
For example:  
1. `I have tried GEN-AI.`  
2. `I use GEN-AI regularly.`  
3. `I use GEN-AI for research.`  
4. `I depend heavily on GEN-AI for research.`  
If someone agrees with 4th statement, the idea is that they would generally agree with the weaker statements too.
👉 Guttman = Steps build on each other.
---

### The only thing you really need to remember

| Technique               | Think                   |
| ----------------------- | ----------------------- |
| `Likert`                | Agree / Disagree    |
| `Semantic Differential` | Opposite ↔ Opposite |
| `Thurstone`             | Pre-assigned values |
| `Guttman`               | Step-by-step        |

### 🧠 One-line memory

`Likert`: agreement/disagreement with statements.  
`Semantic`: we define 2 opposite poles; the user chooses a position between them.  
`Thurstone`: we define statements and assign each statement a value to pick by user.  
`Guttman`: we defines options where choosing the value mostly says we are agreeing over all previous values (cumulative)
