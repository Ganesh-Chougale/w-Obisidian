## 11.1 Meaning of Scaling
`Scaling`: Scaling is more specifically the process of constructing/using a scale to measure the degree of a characteristic.  
- example: measuring how satisfied students are with GEN-AI using `1 = Very dissatisfied` to `5 = Very satisfied`.  
Mental model:  
`Characteristic → Degree/Intensity → Scale`  
Exam yield:  
`Measurement` → assigns a value.  
`Scaling` → shows how much / how strongly a characteristic exists.  


## 11.2 Scale Classification  
`Scale Classification`: grouping scales based on what their values can tell us and what mathematical comparisons are meaningful.  
### 4 Main Classes
`Nominal Scale`: identifies categories/names; no order.  
- example: GEN-AI used → `ChatGPT`, `Gemini`, `Claude`.  
`Ordinal Scale`: shows order/rank, but differences between ranks are not necessarily equal.  
- example: Response quality → `Poor < Average < Good < Excellent`.  
`Interval Scale`: has order + equal intervals, but no true zero.  
- example: Temperature → `10°C, 20°C, 30°C`.  
`Ratio Scale`: has order + equal intervals + true zero.  
- example: Response time → `0 sec, 10 sec, 20 sec`.  
Mental model:  
`Nominal → Ordinal → Interval → Ratio`  
`Name → Rank → Equal gap → True zero`  
Exam yield: These are the 4 fundamental measurement-scale classifications. Know exactly what is added at each level.  


## 11.3 Scaling Techniques
`Scaling Techniques`: methods used to measure people's attitudes, opinions, preferences, or characteristics using a structured scale.
### Main techniques
`Likert Scale`: respondent shows degree of agreement/disagreement.
- example: “Context improves GEN-AI responses.” → `Strongly Agree → Strongly Disagree`
`Semantic Differential Scale`: respondent rates something between two opposite words.
- example: GEN-AI response → `Poor ───── Excellent`
`Thurstone Scale`: uses a set of statements with pre-assigned numerical values; respondent agrees/disagrees with them.
- example: several statements about GEN-AI quality, each already given a scale value.
`Guttman Scale`: statements are arranged from weak to strong; agreeing with a stronger statement generally implies agreement with weaker ones.
- example: `I have tried GEN-AI → I use GEN-AI regularly → I depend on GEN-AI for research`.
Mental model:
`Likert = Agreement`
`Semantic Differential = Opposites`
`Thurstone = Pre-assigned values`
`Guttman = Cumulative / Step-by-step`
Exam yield: Focus on identifying which technique is being described from its defining feature.


## 11.3 Scaling Techniques
`Scaling technique` = a way of asking someone to express their opinion/attitude in numbers or ordered choices.  
Imagine you want to measure:  
> “How good are GEN-AI responses?”  
You can ask the same thing in different ways.  
### 1. Likert Scale = Agree / Disagree  
You give a statement and ask how much the person agrees.  
* “Contextual information improves GEN-AI responses.”  
* `Strongly Agree | Agree | Neutral | Disagree | Strongly Disagree`  
👉 Likert = How much do you agree?  
---

### 2. Semantic Differential = Between Two Opposites (Boolean opinions)
Give two opposite words and ask where the person places their opinion.    
* GEN-AI response:  
`Poor ────●──── Excellent`  
or   
`Useless ───────── Useful`  
👉 Semantic Differential = Where between two opposites?
---

### 3. Thurstone Scale = Statements Already Have Values  
The researcher prepares several statements and assigns values to them beforehand.  
* Statement A → value `2`  
* Statement B → value `5`  
* Statement C → value `8`  
* Statement D → value `10`  
The participant indicates which statements they agree with.
👉 Thurstone = Researcher gives statements pre-assigned values.  
---

### 4. Guttman Scale = Step-by-Step / Cumulative  
Statements are arranged from weak → strong.  
For example:  
1. `I have tried GEN-AI.`  
2. `I use GEN-AI regularly.`  
3. `I use GEN-AI for research.`  
4. `I depend heavily on GEN-AI for research.`  
If someone agrees with 4th statement, the idea is that they would generally agree with the weaker statements too.
👉 Guttman = Steps build on each other.
---

### The only thing you really need to remember

| Technique               | Think                   |
| ----------------------- | ----------------------- |
| `Likert`                | Agree / Disagree    |
| `Semantic Differential` | Opposite ↔ Opposite |

### 🧠 One-line memory

`Likert`: we define agreeing scale.  
`Semantic`: we define 2 opposite poles; the user chooses a position between them.  
`Thurstone`: we define statements and assign each statement a value beforehand.  
`Guttman`: we defines options where choosing the value mostly says we are agreeing over all previous  

Exam yield: Don't try to understand the entire history or construction procedure right now. For MCQs, recognizing the defining feature of each technique is the important part.
