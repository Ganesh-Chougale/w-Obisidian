### Python
```py
print(f"My name is {name}");
```  

### JS
```js
console.log(`My name is ${name}`);
```  

### Java
- these need formatt specifier  
```java
// %s : for string variable
// %d : for decimal variables
// %f : for float variable
// %c : for character variable
// %b : for boolean specifier
System.out.println( String.format("My name is %s", name));
```  

### C#
```csharp
Console.WriteLine($"My name is {name}");
```   

### C++
```c++
std::cout << std::format("My name is {}", name );
```  

### C
```c
printf("My name is %s", name);
```
