## 2. When you write code now, always ask: "Where is the data currently?"
- Before typing: Data doesn't exist.
- After typing: The data exists inside the HTML input element.
- After clicking the button: JavaScript reads the data.
- Later: JavaScript sends the data to the backend.
- Later: Backend receives the data.
- Later: Backend stores the data in PostgreSQL.
And Vice Versa when reading data to frontend from backend
