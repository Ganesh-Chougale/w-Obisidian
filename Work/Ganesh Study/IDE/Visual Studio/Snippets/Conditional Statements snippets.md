# Visual Studio snippets  
## Conditional Statements snippets

1. Creates a basic conditional branch block.
`if` + `tab` :
```csharp
if (true)
{

}
```  


2. Creates a fallback conditional branch block.
`else` + `tab` :
```csharp
else
{

}
```  
3. Creates a multi-option evaluation block based on a single variable.
`switch` + `tab` :
```csharp
switch (switch_on)
{
    default:
}
```
