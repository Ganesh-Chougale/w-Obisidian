SQL Constraints

Constraints are rules enforced on data columns in a table. They are used to limit the type of data that can go into a table, ensuring the accuracy and reliability of the data (data integrity).

The most common constraints are:

1. NOT NULL
- Ensures that a column cannot have a NULL (empty/unknown) value.
```sql
CREATE TABLE Staff (
    EmployeeID INT NOT NULL,
    FirstName VARCHAR(50) NOT NULL,
    LastName VARCHAR(50)
    -- LastName can be NULL, but ID and Name cannot
);
```  
______________________________________________________________________________

2. UNIQUE
Ensures that all values in a column are different. It allows one NULL value (in most SQL databases).
```sql
CREATE TABLE Contacts (
    ContactID INT NOT NULL,
    Email VARCHAR(100) UNIQUE -- Ensures no two contacts have the same email
);
```  
______________________________________________________________________________

3. PRIMARY KEY (PK)
Unique + Not Null
```sql
CREATE TABLE Products (
    ProductID INT PRIMARY KEY, -- This is the unique identifier for every product
    ProductName VARCHAR(100)
);
```  
______________________________________________________________________________

4. FOREIGN KEY (FK)
A foreign key links data between two tables. It is a column (or collection of columns) in one table that refers to the primary key in another table. It enforces referential integrity.
We can cover this extensively when discussing joins, as it explicitly defines the relationship.
```sql
CREATE TABLE Orders (
    OrderID INT PRIMARY KEY,
    ProductID INT,
    FOREIGN KEY (ProductID) REFERENCES Products(ProductID) 
    -- Ensures ProductID here must exist in the Products table
);
```  
______________________________________________________________________________

5. CHECK
Ensures that all values in a column satisfy a specific condition.
```sql
CREATE TABLE Employees (
    EmployeeID INT PRIMARY KEY,
    Age INT CHECK (Age >= 18) -- Ensures every employee is 18 or older
);
```
______________________________________________________________________________

What are Keys?

Keys are specific types of constraints used to establish unique identities for records and links between tables.
- Primary Key (PK): A column that uniquely identifies a row. (e.g., EmployeeID)
- Foreign Key (FK): A column in one table that points to the PK of another table. (e.g., the ProductID in the Orders table above)
- Super Key: A set of columns that uniquely identify a row (PK is a minimal super key).
- Candidate Key: A super key for which no proper subset is a super key (it's "minimal"). The PK is chosen from the candidate keys.
