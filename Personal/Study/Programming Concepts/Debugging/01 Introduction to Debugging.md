## `Debugging`
- debugging is a process to correct the bugs which are found during testing.
## `Bug`
- bug is an error in software system which gives an unexpected result.

debugging is helpful when you are trying to find out why what causing this unexpected result.
so basically there are three types of errors in your code or in your program.

1. Logical error
- outputs un-intended result caused by flawed/wrong logic. 
- detection mostly happens by testers/humans
2. Syntax error 
- outputs un-intended result caused by in-accuracy during coding.
- detection happens by interpreters, compilers or JIT. detect automatically, stops the execution & immediately inform us about it.
3. Run time error / exception
