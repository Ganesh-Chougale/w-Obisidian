Full Join = all values from both tables.
- ✅left | ✅ mid common | ✅right
- basically everything

```txt
1		IT

```

Table 2: Employees (right)
```txt
EmpID(PK)	EmpName		DeptID(FK)
101		Alice		1
```

______________________________________________________________________________

Full join operation:
A. SQL support
```sql
SELECT 
    D.DeptName,
    E.EmpName
FROM 
    Departments D
FULL OUTER JOIN 
    Employees E ON D.DeptID = E.DeptID;
-- Note: In MySQL, FULL OUTER JOIN syntax isn't directly supported 
-- and requires a UNION of a LEFT JOIN and a RIGHT JOIN.
```
______________________________________________________________________________

B. LINQ support
B1. Method Syntax:
```csharp
// 1. Perform a LEFT OUTER JOIN
var leftJoin = Departments.GroupJoin(Employees, d => d.DeptID, e => e.DeptID, (d, eGroup) => new { d, eGroup })
                          .SelectMany(temp => temp.eGroup.DefaultIfEmpty(), 
                                      (temp, e) => new { DeptName = temp.d.DeptName, EmpName = e?.EmpName });

// 2. Perform a RIGHT OUTER JOIN (by swapping collections and doing a Left Join logic)
var rightJoin = Employees.GroupJoin(Departments, e => e.DeptID, d => d.DeptID, (e, dGroup) => new { e, dGroup })
                         .SelectMany(temp => temp.dGroup.DefaultIfEmpty(), 
                                     (temp, d) => new { DeptName = d?.DeptName, EmpName = temp.e.EmpName });

// 3. Combine the results using Union() to remove duplicates
var fullJoinResult = leftJoin.Union(rightJoin);
```

B2. Query Syntax:
```csharp
// 1. Get Left Join results (as defined in the previous example)
var leftJoinQuery = from d in Departments
                    join e in Employees on d.DeptID equals e.DeptID into EmployeeGroup
                    from emp in EmployeeGroup.DefaultIfEmpty()
                    select new { DeptName = d.DeptName, EmpName = emp?.EmpName };

// 2. Get Right Join results (as defined in the previous example)
var rightJoinQuery = from e in Employees
                     join d in Departments on e.DeptID equals d.DeptID into DepartmentGroup
                     from dept in DepartmentGroup.DefaultIfEmpty()
                     select new { DeptName = dept?.DeptName, EmpName = e.EmpName };

// 3. Combine the results using Union()
var fullJoinResult = leftJoinQuery.Union(rightJoinQuery);
```
