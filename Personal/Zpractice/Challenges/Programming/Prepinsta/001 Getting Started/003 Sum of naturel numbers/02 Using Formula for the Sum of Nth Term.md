## 003-02. Find the Sum of N Natural Numbers 

Given an integer input the objective is to write a code to Find the Sum of N Natural Numbers. To do so we simply keep adding the value of the iter variable using a for loop.  

- Method 2: Using Formula for the Sum of Nth Term

### Python
```py
def sumOfN(num):
    sum = (num * (num + 1)) / 2;
    print (f"Sum of first {num} is : {sum}");

sumOfN(10)
```

### JS
```js
function sumOfN(num){
    let sum = (num * (num + 1)) / 2;
    console.log(`some of first ${num} numbers is: ${sum}`);
}

sumOfN(10)
```
