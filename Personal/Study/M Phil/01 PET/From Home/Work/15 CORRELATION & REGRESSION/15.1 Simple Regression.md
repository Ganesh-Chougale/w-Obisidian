## 15.1 Simple Regression  
`Simple Regression`: A statistical method used to estimate or predict one variable (dependent variable) using one other variable (independent variable).  
Think:  
> “If X changes, what value of Y can we expect?”  
- Independent variable (X) → the factor used to explain/predict.  
- Dependent variable (Y) → the outcome we want to estimate.  

- example: Study hours → Exam marks  
  * `X = Study hours`  
  * `Y = Exam marks`  
  * Regression estimates how exam marks tend to change as study hours change.  

The basic regression line is:  
`Y = a + bX`  

`X` → input/predictor  
`Y` → estimated outcome  
`a` → starting/intercept value  
`b` → how much Y changes when X increases by 1 unit  


Remember:
`Regression` → How can X be used to estimate Y?
`Correlation` → How strongly are X and Y related?
