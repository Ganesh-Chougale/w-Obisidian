## 13.2 Coding
`Coding`: Converting collected data into **numbers, symbols, or categories*- so it can be **classified, tabulated, and analysed**.    
- example: For a question *“Do you use GEN-AI?”*  
  `Yes = 1`  
  `No = 2`  

- example: For satisfaction:  
  `Very satisfied = 1`  
  `Satisfied = 2`  
  `Neutral = 3`  
  `Dissatisfied = 4`  

`Raw Data` → `Codes/Categories` → `Classification` → `Analysis`  
**Remember:*- Coding does **not*- mean changing the meaning of the data. It gives responses a **standard form that makes analysis easier**.  

**Exam hook:**  
`Coding = assigning symbols/numbers to responses for easier classification and analysis.`
