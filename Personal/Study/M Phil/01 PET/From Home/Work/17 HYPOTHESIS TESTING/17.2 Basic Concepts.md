## 17.2 Basic Concepts
`Hypothesis Testing`: A statistical method used to decide whether **sample data provides enough evidence** to support a claim about a population.  

### 1. Null Hypothesis (`H₀`)  
`H₀`: Says **there is no effect, difference, or relationship**.  
- example: A new teaching method does **not** change students' average scores.  
 
### 2. Alternative Hypothesis (`H₁` / `Hₐ`)
`H₁`: Says **there is an effect, difference, or relationship**.  
- example: A new teaching method **changes** students' average scores.  

### 3. Test Statistic
`Test Statistic`: A value calculated from the sample data to determine how strongly the data differs from what `H₀` expects.  

### 4. Significance Level (`α`)
`α`: The maximum probability of **rejecting a true H₀** that we are willing to accept.  
Common value: `α = 0.05` → `5%`  

### 5. p-value
`p-value`: Tells us how unusual the observed sample result would be **if H₀ were true**.  
- Small `p-value` → stronger evidence against `H₀`.  
- Large `p-value` → not enough evidence against `H₀`.  

### 6. Decision
- `p-value ≤ α` → **Reject H₀**  
- `p-value > α` → **Fail to reject H₀**  

### Core mental model
`H₀` → Assume it is true → `Collect Sample Data` → `Calculate Test Statistic / p-value` → `Make Decision`  

### Remember
**Hypothesis testing does not simply prove that H₀ is true or false.**  
It asks: **“Does the sample give us enough evidence to reject H₀?”**
