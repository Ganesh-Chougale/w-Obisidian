## General & Power Pins

| Short Form | Long Form | Description |
|---|---|---|
| GP | General Purpose (GPIO) | Programmable digital input/output pins |
| GND | Ground | Common negative reference point for the circuit |
| VBUS | Power from USB | 5V power supply from the micro-USB port |
| VSYS | System Voltage | Main system input voltage (1.8V to 5.5V) |
| 3V3 | 3.3 Volts | Main regulated 3.3V power output |
| EN | Enable | Regulator control pin (turns power on/off) |

## Communication Protocols

| Short Form | Long Form | Description |
|---|---|---|
| UART | Universal Asynchronous Receiver-Transmitter | Standard serial communication protocol |
| TX | Transmit | Data output line for serial communication |
| RX | Receive | Data input line for serial communication |
| I2C | Inter-Integrated Circuit | Two-wire serial communication protocol |
| SDA | Serial Data | Data line for I2C communication |
| SCL | Serial Clock | Clock line for I2C communication |
| SPI | Serial Peripheral Interface | Fast four-wire serial communication protocol |
| CSn | Chip Select (Active Low) | Pin used to activate a specific SPI slave device |
| SCK | Serial Clock | Clock line for SPI communication |

## Analog Controls

| Short Form | Long Form | Description |
|---|---|---|
| ADC | Analog-to-Digital Converter | Converts analog voltage signals into digital values |
| VREF | Voltage Reference | Input voltage reference for the ADC system |
| AGND | Analog Ground | Dedicated ground plane for clean analog readings |
| PWM | Pulse Width Modulation | Simulates analog signals using digital pulses |

## System & Debugging

| Short Form | Long Form | Description |
|---|---|---|
| RUN | Run / Reset | Reset pin (reboots the microcontroller when pulled low) |
| SWCLK | Serial Wire Clock | Clock line for the Serial Wire Debugging (SWD) protocol |
| SWDIO | Serial Wire Data Input/Output | Bi-directional data line for debugging and flashing code |
