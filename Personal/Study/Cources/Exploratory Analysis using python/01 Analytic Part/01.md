1. Data Mining: its the process or technique to detect pattern in data.  
2. Data Analytics: Data analytics is using qualitative or quantitative approaches or techniques to get insights from data we have.  
3. Data Analysis: Data analysis is about cleaning, transorming, analyzing or visualizing data so that the users can really understand what is happening or what has happened in the data & which can help them take action.  
4. Data Science = [Data Analysis [Data Analytics [Data Mining] ] ] combined all.
