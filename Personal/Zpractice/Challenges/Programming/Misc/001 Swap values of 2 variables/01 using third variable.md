## 001-01. swap the values of 2 variables

- using 3rd variable

### Python
```py
var1 = 5;
var2 = 10;
print(f"value of variable1 is: {var1} & value of variable2is: {var2}");

temp = var1;

var1 = var2;
var2 = temp;
print(f"value of variable1 is: {var1} & value of variable2is: {var2}");
```

### JS
```js
let var1 = 5;
let var2 = 10;
console.log(`value of variable1 is: ${var1} & value of variable2is: ${var2}`);

let temp = var1;

var1 = var2;
var2 = temp;
console.log(`value of variable1 is: ${var1} & value of variable2is: ${var2}`);
```
