- Employee by department id
- Department wise employee
```sql
DECLARE @DeptId INT = '1010000025'; 

SELECT
	(EMP.EMPLOYEE_FIRST_NAME ) + ' ' + (EMP.EMPLOYEE_MIDDLE_NAME ) + ' ' + (EMP.EMPLOYEE_LAST_NAME) AS FULL_NAME,
	EMP.EMPLOYEE_SHORT_NAME,
	ISNULL(FORMAT(CAST(EMP.BIRTH_DATE AS DATE), 'dd/MM/yyyy'), '') AS BIRTH_DATE,
	ISNULL(FORMAT(CAST(EMP.JOIN_DATE AS DATE), 'dd/MM/yyyy'), '') AS JOIN_DATE,
	DEPT.DEPARTMENT_NAME,
	DEPT.DEPARTMENT_SHORT_NAME
FROM
	ERP_MASTERS..MST_EMPLOYEE AS EMP

	LEFT JOIN ERP_MASTERS..MST_DEPARTMENT AS DEPT
	ON EMP.PAYROLL_DEPT = DEPT.DEPARTMENT_ID

WHERE
	DEPT.DEPARTMENT_ID = @DeptId
ORDER BY EMP.JOIN_DATE DESC;
```   
- IT department Id = 1010000025
