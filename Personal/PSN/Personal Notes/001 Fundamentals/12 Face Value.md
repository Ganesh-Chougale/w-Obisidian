# `Face Value`

### Face Value = `the base value assigned to a share when the company creates it`

It is just a **starting number used for accounting**.

It **does NOT tell the real market value** of the company.

---

# Simple example

Suppose a company starts by issuing shares like this:

| Item                      | Value     |
| ------------------------- | --------- |
| Total money company wants | ₹10 crore |
| Face Value per share      | ₹10       |

Number of shares created:

```text
Shares = ₹10 crore / ₹10
Shares = 1 crore shares
```

So each share **represents ₹10 of company capital**.

---

# What happens later in the market

After listing on the stock market, investors trade the shares.

Example:

| Item          | Value |
| ------------- | ----- |
| Face Value    | ₹10   |
| Current Price | ₹450  |

Meaning:

```text
Original accounting value = ₹10
Market value decided by investors = ₹450
```

Face value **stays ₹10 forever** (unless a split happens).

---

# Why Face Value exists

It helps define the **company's share capital**.

Example:

| Item          | Value   |
| ------------- | ------- |
| Shares issued | 1 crore |
| Face value    | ₹10     |

```text
Share Capital = ₹10 crore
```

This number appears in the company's **balance sheet**.

---

# Where Face Value is actually used

### 1️⃣ Dividend announcements

Companies sometimes declare dividend like:

```text
Dividend = 100% of face value
```

If face value = ₹10

```text
Dividend = ₹10 per share
```

---

### 2️⃣ Stock splits

Example:

Before split:

| Face Value | ₹10 |
| ---------- | --- |
| Shares     | 1   |

Company does **1:5 split**

After split:

| Face Value | ₹2 |
| ---------- | -- |
| Shares     | 5  |

Total value stays same.

---

# Important rule

```text
Face Value ≠ Share Price
```

Example:

| Company   | Face Value | Price |
| --------- | ---------- | ----- |
| Company A | ₹1         | ₹2800 |
| Company B | ₹10        | ₹120  |

Face value **does not show cheap or expensive stock**.

---

# One sentence to remember

```text
Face Value = original accounting value of a share
```

Market price is decided by **buyers and sellers**, not face value.
