## Types of function  
a function is grouped logic binded in a codeblock which work when we call that codeblock. similarly if function is kept inside a class/object we identify that function as `Method`.  
- 01 Data Requesting function
- 02 Data Retrieving function
- 03 Data Filtering function
- 04 Data Saving function
- 05 Formula function
- 06 Data Mapping/Binding/Assigning function
- 07 API Exposing function
- 08 Formatting function
- 09 Data Collecting/Gathering function
- 10 Data Posting function
