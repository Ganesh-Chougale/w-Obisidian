## 15.3 Multiple Regression
`Multiple Regression`: A statistical method used to predict one dependent variable (`Y`) using two or more independent variables (`X`).  

- example:
  * `Study Hours (X₁)`  
  * `Attendance (X₂)`  
  * `Previous Marks (X₃)`  
  * → predict `Exam Marks (Y)`  

It tells us how the different X factors together can be used to estimate Y.  

`X₁ + X₂ + X₃ ...` → Regression Model → `Predicted Y`  

### Mental model
> “Can I predict Y using several X factors?”  

Easy distinction:  

`Multiple Correlation` → measures relationship  
`Multiple Regression` → predicts Y
