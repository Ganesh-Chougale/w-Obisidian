QMessage is popup name in QT

| Enum Constant | Description |
|---|---|
| QMessageBox::Ok | Confirms an action or closes an information prompt. |
| QMessageBox::Cancel | Aborts the operation without saving or applying changes. |
| QMessageBox::Yes | Positive response to a binary query. |
| QMessageBox::No | Negative response to a binary query. |
| QMessageBox::Save | Saves the current work. |
| QMessageBox::Discard | Closes without saving changes. |
| QMessageBox::Open | Opens an existing file or resource. |
| QMessageBox::Close | Closes the dialog or current view. |
| QMessageBox::Apply | Applies changes immediately while keeping the dialog open. |
| QMessageBox::Reset | Resets all fields or properties to their initial setup values. |
| QMessageBox::RestoreDefaults | Restores the configuration to factory default properties. |
| QMessageBox::Help | Requests context-sensitive application help information. |
| QMessageBox::SaveAll | Saves all open resources or files at once. |
| QMessageBox::YesToAll | Responds positively to current and subsequent identical prompts. |
| QMessageBox::NoToAll | Responds negatively to current and subsequent identical prompts. |
| QMessageBox::Abort | Aborts the execution of the current structural operation. |
| QMessageBox::Retry | Tries executing the failed configuration or action again. |
| QMessageBox::Ignore | Ignores the current warning/error and continues execution. |
| QMessageBox::NoButton | Displays an empty layout containing no buttons. |
