# Why **Face Value** exists (Historical Reason)

To understand face value, we must go back to **old company days before stock markets became modern**.

Earlier, shares were **physical paper certificates**.

---

# Step 1 — Company needed money

Suppose someone wanted to start a company.

They decide:

```text id="4m9a9n"
We need ₹10 lakh to start this business
```

Instead of asking one person, they divide ownership.

---

# Step 2 — Divide company into shares

Company says:

```text id="m0icub"
Each share = ₹10
```

Now total shares become:

```text id="0mlrgl"
₹10 lakh / ₹10 = 1 lakh shares
```

That **₹10 printed on the certificate** became the:

```text id="njp4j3"
Face Value
```

It was literally printed on the paper share certificate.

---

# Step 3 — People start trading those shares

Later investors started buying and selling shares.

Example:

| Printed on certificate | Market trade |
| ---------------------- | ------------ |
| ₹10                    | ₹50          |
| ₹10                    | ₹200         |
| ₹10                    | ₹800         |

So the **market price changed**, but the **printed face value stayed same**.

---

# Why companies still keep Face Value today

Even though shares are now **digital**, the concept remains because it helps with:

### 1️⃣ Share capital accounting

Example:

| Shares     | 1 crore |
| ---------- | ------- |
| Face Value | ₹10     |

```text id="oabkak"
Share Capital = ₹10 crore
```

This appears in financial statements.

---

### 2️⃣ Stock splits

Example:

Before split:

| Face Value | ₹10   |
| ---------- | ----- |
| Price      | ₹1000 |

Company splits stock:

```text id="haj7k2"
₹10 → ₹2
```

Now:

| Shares | 5x   |
| ------ | ---- |
| Price  | ₹200 |

Same company value, but **shares become more affordable**.

---

### 3️⃣ Dividend calculation

Companies sometimes say:

```text id="9qf5pl"
Dividend = 200% of face value
```

If face value = ₹10

```text id="q0q73y"
Dividend = ₹20
```

---

# The easiest way to remember Face Value

Think of it like:

```text id="k4h4ne"
The "birth value" of a share
```

or

```text id="e2psqs"
the number written when the share was created
```

Market price is what **people later decide it is worth**.

---

# One simple picture in mind

| Concept      | Meaning                      |
| ------------ | ---------------------------- |
| Face Value   | original printed value       |
| Market Price | what investors currently pay |
| Book Value   | company net worth per share  |
