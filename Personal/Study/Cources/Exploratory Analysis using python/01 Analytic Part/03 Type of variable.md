# `Types of variable`
## A. Qualitative (Categorical)

`A1. Dichotomous (Binary)`  
• Exactly 2 categories
Examples:
- Yes / No
- Pass / Fail
- Married / Unmarried

`A2. Polytomous`  
• More than 2 categories
Examples:
- Hair Color
- PC Brand
- Blood Group
- Country

----------------------------------------------------

## B. Quantitative (Numerical)

`B1. Discrete`  
• Countable values  
• Usually whole numbers  
Examples:
- Number of students
- Family members
- Number of cars

`B2. Continuous`  
• Measured values  
• Can contain decimals  
Examples:
- Height
- Weight
- Temperature
- Time
- Distance

## Easy way to remember
- `Qualitative` → Labels/Categories ("What type?")
- `Quantitative` → Numbers ("How many?" or "How much?")
