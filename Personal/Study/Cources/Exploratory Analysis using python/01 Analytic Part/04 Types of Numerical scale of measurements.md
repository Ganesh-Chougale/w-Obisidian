# Types of numerical scale of measurement  

## A. Nominal
• Used only for labeling or naming categories.
• No natural ordering between categories.
Examples:
- Gender
- Blood Group
- Hair Color
- Country

----------------------------------------------------

## B. Ordinal
• Categories have a meaningful order or ranking.
• Difference between ranks is not measurable.
Examples:
- Education Level (High School, Bachelor's, Master's)
- Customer Rating (1★, 2★, 3★, 4★, 5★)
- T-Shirt Size (S, M, L, XL)

----------------------------------------------------

## C. Interval
• Ordered numerical values.
• Equal intervals between values.
• No true (absolute) zero.
• Addition and subtraction are meaningful.
Examples:
- Temperature (°C, °F)
- Calendar Year
- IQ Score

----------------------------------------------------

## Ratio
    • Ordered numerical values.
    • Equal intervals between values.
    • Has a true (absolute) zero.
    • All arithmetic operations (+, −, ×, ÷) are meaningful.
    Examples:
    - Height
    - Weight
    - Age
    - Salary
    - Distance
    - Time Duration


### Easy way to remember

| Scale        | Categories? | Ordered? | Equal Difference? | True Zero? | Example             |
| ------------ | ----------- | -------- | ----------------- | ---------- | ------------------- |
| **Nominal**  | ✅           | ❌        | ❌                 | ❌          | Gender              |
| **Ordinal**  | ✅           | ✅        | ❌                 | ❌          | Rating (1–5)        |
| **Interval** | ❌           | ✅        | ✅                 | ❌          | Temperature (°C)    |
| **Ratio**    | ❌           | ✅        | ✅                 | ✅          | Height, Weight, Age |

### Memory Trick

* **Nominal** → **Name**
* **Ordinal** → **Order**
* **Interval** → **Intervals are equal, but no true zero**
* **Ratio** → **Everything Interval has + a true zero**
