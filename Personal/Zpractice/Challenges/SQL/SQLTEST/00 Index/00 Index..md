
| Category Name | Description |
| :--- | :--- |
| **Database theory** | Covers the fundamental architectural concepts of databases, such as relational design, normalization, keys (primary/foreign), and schemas. |
| **SQL Basics** | Focuses on foundational queries using `SELECT`, `FROM`, `WHERE`, `ORDER BY`, and simple table joins to retrieve data. |
| **Calculations** | Involves performing arithmetic operations, manipulating strings, handling dates, and using built-in scalar functions within queries. |
| **Aggregation Functions** | Uses functions like `SUM()`, `AVG()`, `COUNT()`, `MIN()`, and `MAX()`, usually paired with `GROUP BY` and `HAVING` to summarize data. |
| **Subqueries** | Covers nesting one query inside another (in `SELECT`, `FROM`, or `WHERE` clauses) to perform multi-step data retrieval. |
| **Common Table Expressions (CTE)** | Uses the `WITH` clause to define temporary, reusable result sets that make complex queries cleaner and easier to read. |
| **Window Functions** | Applies analytical functions (like `ROW_NUMBER()`, `RANK()`, `LEAD()`, or `LAG()`) across a specific set of rows related to the current row without collapsing them. |
| **Analytical queries** | Focuses on advanced data analysis, business intelligence tracking, trend reporting, and complex reporting metrics. |
| **Data manipulation queries (DML)** | Deals with modifying data inside tables using statements like `INSERT`, `UPDATE`, and `DELETE`. |
| **Data Definition Language (DDL)** | Focuses on creating, altering, and destroying database structures themselves using `CREATE`, `ALTER`, and `DROP`. |
| **Geospatial data (PostGIS)** | Involves querying spatial geographic objects (points, lines, polygons) using the PostGIS extension for location-based data. |
| **Data Engineering** | Covers advanced tasks like schema optimization, indexing strategies, data pipeline transformation logic, and bulk loading. |
