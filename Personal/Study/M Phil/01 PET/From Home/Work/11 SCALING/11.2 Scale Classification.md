## 11.2 Scale Classification  
`Scale Classification`: grouping scales based on what their values can tell us and what mathematical comparisons are meaningful.  
### 4 Main Classes
`Nominal Scale`: identifies categories/names; no order.  
- example: GEN-AI used → `ChatGPT`, `Gemini`, `Claude`.  
`Ordinal Scale`: shows order/rank, but differences between ranks are not necessarily equal.  
- example: Response quality → `Poor < Average < Good < Excellent`.  
`Interval Scale`: has order + equal intervals, but no true zero.  
- example: Temperature → `10°C, 20°C, 30°C`.  
`Ratio Scale`: has order + equal intervals + true zero.  
- example: Response time → `0 sec, 10 sec, 20 sec`.  
Mental model:  
`Nominal → Ordinal → Interval → Ratio`  
`Name → Rank → Equal gap → True zero`  
Exam yield: These are the 4 fundamental measurement-scale classifications. Know exactly what is added at each level.
