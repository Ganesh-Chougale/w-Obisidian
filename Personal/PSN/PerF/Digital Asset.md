# Interesting Pattern

Most successful digital assets do one of these:

| Purpose               | Example          |
| --------------------- | ---------------- |
| Save time             | templates/tools  |
| Make money            | automation       |
| Entertain             | games/music      |
| Educate               | courses/books    |
| Improve status        | design/cosmetics |
| Reduce pain           | utilities        |
| Increase productivity | software         |

# The Superpower of Digital Assets

Digital assets can have:

```text id="62g4y8"
high scalability
+
near-zero reproduction cost
+
global distribution
```

That combination is historically unusual.

A farmer cannot duplicate one farm infinitely.

But software can be copied millions of times.
